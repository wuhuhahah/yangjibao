【养基宝看板 使用说明】

日常只需要两个动作：
1. 平时想看持仓 → 双击「持仓看板.html」（浏览器打开）
2. 改了持仓或想更新数据 → 双击「刷新数据.bat」（自动同步 + 体检 + 弹出看板）

关于 Edge
  刷新数据.bat 会自己处理 Edge，不需要你提前关：
    · 检测到 Edge 在跑 → 问一句，直接回车（或输 Y）就自动关掉 Edge，
      同步完持仓后自动把 Edge 重新打开
    · 输 n → 只更新净值/估值/技术面，不动 Edge，持仓沿用上次的
  为什么非要关 Edge：工具读的是插件存在本地的数据快照，
  而新版 Edge 不允许在浏览器的默认资料目录上开调试端口，
  所以流程是「关掉 Edge → 拷贝插件数据 → 另起一个后台 Edge 读出来」。
  这是 Edge 的限制，跟养基宝的接口没关系。

怎么确认持仓真的同步了
  看板标题右边写着「持仓更新 X月X日 X:XX」。
  这个时间应该是你刚改完持仓的时间；如果还是旧日期，就说明持仓没同步成功。

每周日 20:00 Windows 会自动刷新一次（任务名：养基宝周报）
  定时任务不会去关 Edge，所以它只更新市场数据，不更新持仓。

文件夹里其他文件是引擎，不用管：
  yjb.js / portfolio.py            引擎脚本
  yjb-data.json / nav_cache.json   数据与缓存
  weekly_report.bat                周报定时任务入口
  *.bak                            改造前的备份，出问题可以还原

数据辅助分析，不构成投资建议。
